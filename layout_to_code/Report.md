# Отчет о соответствии макету

## Соответствует:

- [x] Цветовая палитра
- [x] Типографика (семейства шрифтов)
- [x] Расположение элементов (структура сетки)
- [x] Размеры основных блоков (десктоп)
- [x] Семантическая верстка (теги header, main, section, article)
- [x] Оптимизация ресурсов (шрифты, lazy-load для картинок)

## Требует доработки:

- [ ] Отступы между секциями (вертикальный ритм)
- [ ] Размеры кнопок и их отступы (padding)
- [ ] Выравнивание текста (в некоторых блоках)
- [ ] Адаптивность (мобильная версия требует тестов)
- [ ] Размеры изображений (устранение CLS)

## Примечания:
- Шрифты 'Space Grotesk' и 'Poppins' объединены в один запрос к Google Fonts. Если шрифты не загрузятся, используется fallback (Verdana, Tahoma).
- Удален жестко заданный `height: 6411px` у `body`, из-за чего общая высота страницы теперь зависит от контента (это хорошо для адаптивности, но требует проверки).
- В HTML добавлены атрибуты `width` и `height` для изображений, а также `loading="lazy"`, что улучшает показатели Core Web Vitals (устраняет скачки макета).
