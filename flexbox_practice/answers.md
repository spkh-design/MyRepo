## Вопрос 1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?
display: flex (или inline-flex). Элемент становится flex-контейнером, а его прямые дочерние элементы – flex-элементами: выстраиваются вдоль главной оси, могут растягиваться, сжиматься и выравниваться; float и vertical-align на них перестают действовать.

## Вопрос 2. В чем разница между justify-content и align-items? Приведите примеры использования каждого.
justify-content выравнивает элементы вдоль главной оси (по умолчанию горизонтали), align-items – вдоль поперечной (по умолчанию вертикали).
Пример: justify-content: space-between – элементы распределяются по горизонтали; align-items: center – выравниваются по вертикали по центру.

## Вопрос 3. Что делает свойство flex-direction и какие значения может принимать? Как оно влияет на основную ось?
Задаёт направление главной оси. Значения: row (по умолчанию), row-reverse, column, column-reverse. От него зависит, какая ось главная: при row – горизонталь, при column – вертикаль, и соответственно меняется действие justify-content и align-items.

## Вопрос 4. Объясните значение трех свойств в сокращенной записи flex: 1. Что означают flex-grow, flex-shrink и flex-basis?
flex: 1 = flex: 1 1 0%. flex-grow: 1 – элемент растягивается, забирая свободное место; flex-shrink: 1 – может сжиматься; flex-basis: 0% – базовый размер до распределения места. Итог: элементы делят пространство поровну.

## Вопрос 5. Как работает свойство flex-wrap и в каких случаях его следует использовать?
Определяет перенос элементов на новую линию. Значения: nowrap (по умолчанию), wrap, wrap-reverse. Используется для адаптивных сеток и списков, которые должны перестраиваться при нехватке места без медиа-запросов.

## Вопрос 6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?
align-items выравнивает отдельные элементы внутри одной линии по поперечной оси. align-content выравнивает сами линии и работает только при flex-wrap: wrap/wrap-reverse, когда линий больше одной.

## Вопрос 7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?
Меняет порядок отображения без изменения HTML. По умолчанию order: 0; меньшее значение – раньше, большее – позже. Полезно, например, вынести важный блок в начало на мобильных или поменять порядок колонок в адаптивном дизайне.

## Вопрос 8. Что такое "осевая линия" (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?
Главная ось – вдоль неё располагаются элементы, поперечная – перпендикулярна ей. Их ориентацию задаёт flex-direction: при row главная – горизонталь, поперечная – вертикаль; при column – наоборот. justify-content работает по главной оси, align-items/align-content – по поперечной.

## Вопрос 9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.
Использовать flex-wrap: wrap + гибкий flex-basis.

.container { display: flex; flex-wrap: wrap; gap: 16px; }
.item { flex: 1 1 250px; }

Элементы переносятся и растягиваются в зависимости от ширины контейнера.

## Вопрос 10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?
gap задаёт отступы только между элементами, без краевых. Не нужны отрицательные margins и селекторы :last-child/:first-child. Код чище, отступы не схлопываются, можно задавать отдельно для строк и колонок (gap: 10px 20px).
